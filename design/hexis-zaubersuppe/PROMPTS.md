# Hexis Zaubersuppe – Bildprompts (ChatGPT)

Jeder Prompt beginnt mit demselben Stil-Satz:

> Süßer, runder Cartoon-Stil für ein Kinder-Handyspiel ab 5 Jahren, weiche Formen, dicke dunkle Outlines, kräftige freundliche Farben, Halloween-gemütlich, nichts Gruseliges, keine Schrift.

Danach das Motiv, für Figuren und Zutaten jeweils „Transparenter Hintergrund, PNG, quadratisch.“

| Datei | Motiv |
|---|---|
| `hexe.png`, `hexe-jubel.png`, `hexe-ueberrascht.png` | Hexe Hexi (lila Hut mit gelbem Stern, orange Haare, grünes Kleid): steht lächelnd / jubelt / Hand vor dem Mund |
| `kater.png` | Kater Kasimir: kleiner schwarzer Kater, gelbe Augen, oranges Halstuch, sitzt |
| `kater-lila.png`, `kater-fluegel.png`, `kater-hut.png`, `kater-kuerbis.png`, `kater-regenbogen.png`, `kater-winzig.png` | Verwandlungen: lila Glitzerfell / Fledermausflügel / viel zu großer Hexenhut / Kürbiskostüm / Regenbogenfell / winzig mit riesigem Kopf |
| `kessel.png` | Hexenkessel auf drei Füßen mit Feuer, **hellgraue** Suppe (wird im Spiel eingefärbt) |
| `rauchwolke.png` | bunte „Puff“-Wolke in Lila und Grün mit Sternen |
| `frosch.png` … `beeren.png` | Zutaten: Frosch, Kürbis, Stern, Fliegenpilz, Fledermaus, Apfel, Bonbon, Feder, Mondsichel, Zauberbeeren |
| `hintergrund.png` | Hexenküche im Hochformat 9:16, unteres Drittel frei, keine Figuren |
| `kachel.png`, `social-preview.png` | Titelbild quadratisch ohne Schrift / 1200×630 mit Schriftzug |

`musik-original.mp3`: Hintergrundlied (Pixabay, „Halloween Spooky“ von Nastelbom), vom Auftraggeber geliefert.
Aufbereiten: `python3 tools/hexis-zaubersuppe-assets.py`.
